# Weather Tracker

Веб-приложение для отслеживания погоды.

Weather Tracker позволяет пользователям регистрироваться, искать локации по всему миру и вести персональную коллекцию мест с актуальными погодными данными. Приложение предоставляет чистый и адаптивный интерфейс для мониторинга текущих погодных условий в нескольких локациях.

## Обзор

### Управление пользователями
- Регистрация и аутентификация пользователей
- Безопасное хеширование паролей с BCrypt
- Авторизация на основе сессий с кастомной реализацией
- Выход из системы

### Управление локациями
- Поиск локаций по всему миру по названию
- Добавление локаций в персональную коллекцию
- Просмотр текущей погоды для сохраненных локаций
- Удаление локаций из коллекции

### Погодные данные
- Актуальная погодная информация от OpenWeatherMap API
- Хранение географических координат

## Технологический стек

### Бэкенд
- **Java** - основная логика приложения
- **Spring MVC** - веб-фреймворк (без Spring Boot)
- **Hibernate** - ORM для работы с базой данных
- **Maven** - управление зависимостями и сборка

### Фронтенд
- **Thymeleaf** - шаблонизатор
- **Bootstrap 5** - адаптивный UI-фреймворк
- **HTML5/CSS3** - разметка и стили

### База данных
- **PostgreSQL** - основная база данных
- **Flyway** - миграции базы данных
- **HikariCP** - пул соединений (в планах)

### Внешние сервисы
- **OpenWeatherMap API** - поставщик погодных данных
- **Java HTTP Client** - коммуникация с API

### Тестирование
- **JUnit 5** - фреймворк для тестирования
- **Интеграционные тесты** - тестирование сервисного слоя
- **Mock HTTP Client** - тестирование API

## Схема базы данных

### Таблица Users
- `id` - Первичный ключ (автоинкремент)
- `login` - Уникальный логин/email
- `password` - BCrypt хеш пароля

### Таблица Locations
- `id` - Первичный ключ (автоинкремент)
- `name` - Название локации
- `user_id` - Внешний ключ на users
- `latitude` - Географическая широта
- `longitude` - Географическая долгота
- Уникальное ограничение на (latitude, longitude)

### Таблица Sessions
- `id` - UUID первичный ключ
- `user_id` - Внешний ключ на users
- `expires_at` - Время истечения сессии

## Ключевые особенности реализации

### Система аутентификации
- Кастомное управление сессиями без Spring Security
- Ручная работа с cookies для сохранения сессий
- Управление временем жизни сессий

### Интеграция с API
- OpenWeatherMap Geocoding API для поиска локаций и погоды


### Безопасность
- Хеширование паролей с BCrypt
- Защита от SQL-инъекций через Hibernate
- Защита от XSS через Thymeleaf

## Начало работы

### Предварительные требования
- Java 17 или выше
- База данных PostgreSQL
- Maven 3.6+
- API ключ OpenWeatherMap

### Установка
1. Клонируйте репозиторий
2. Настройте подключение к базе данных в `application.properties`
3. Установите API ключ OpenWeatherMap
4. Запустите миграции базы данных через Flyway
5. Соберите проект: `mvn clean package`
6. Разверните на Tomcat сервере

## Тестирование

Проект включает комплексные интеграционные тесты:
- Тесты сервисов пользователей с in-memory базой данных
- Тесты управления сессиями
- Тесты с моком OpenWeatherMap API
